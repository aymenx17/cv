DRAWING QUALITY01
Drawing→Review→Evaluate

Engineering / Quality assurance

Technical drawings.
Clearer quality checks.

Developing software for checking technical drawings, with tools to inspect findings and compare analysis results.

The review interface brings original and modified drawings, error records, and evaluation measures into one place.

  • Quality checks
  • Evaluation
  • React & TypeScript
Inside the work +

The problem. Reviewers need to understand what was found and how results change between analyses.

The implementation. A drawing viewer paired with error-level inspection, precision and recall summaries, and checks for inconsistencies in evaluation records.

The focus. Make results traceable and easier to assess, including missed errors and extra findings.

COMPUTER VISION02
Segment→Classify→Review

Retail / Applied computer vision

Recognizing products.
Making counts matter.

Computer vision development for grocery-product recognition and counting, combining instance segmentation with AI-assisted classification.

The work explores how to handle crowded scenes, ambiguous product views, and errors that affect the final count.

  • Instance segmentation
  • AI agents
  • Python
Inside the work +

The problem. Occlusion, similar packaging, and imperfect segmentation make product-level counts harder than counting detection boxes.

The approach. Combine segmentation and classification with targeted review of uncertain predictions.

The evaluation. Inspect counts, product labels, failure cases, and computational cost together.
