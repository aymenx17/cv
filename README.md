# Aymen Sayed — Professional portfolio

A responsive, static portfolio for GitHub Pages. Open `index.html` in a browser or serve this directory locally. No build step or JavaScript framework is required.

## Files

- `index.html`: page content and illustrative SVG diagrams
- `styles.css`: responsive design and typography
- `profile_image.jpg`: existing profile photograph
- `favicon.svg`: site icon

Typography uses native system fonts. The existing editorial layout is retained, with refined spacing, rounded cards, and stronger text contrast. The drawing-quality card uses a cropped public engineering drawing from HAER NM-16, sheet 6 (National Park Service / Library of Congress), listed as U.S. public domain. It is an illustrative example, not client material. The other illustrations are conceptual diagrams. Contact and profile links come from the existing portfolio.

## Verification

Checked in a browser at 320, 390, 768, and 1280 pixels wide for horizontal overflow. Desktop and phone layouts were inspected visually. Section links, local assets, and all three expandable notes were checked. No browser warnings or errors were reported.
